# AgriAssist-AI
AI-powered agriculture assistant for farmers.

# Project Overview

AgriAssist AI helps farmers make better agricultural decisions using artificial intelligence. The platform provides crop recommendations, weather insights, disease detection, and smart farming assistance.

# Features

- Crop Recommendation System
- Weather Monitoring
- Plant Disease Detection using AI
- Smart Farming Suggestions
- Market Price Updates

# Tech Stack

- Frontend: Next.js / React
- Backend: Node.js
- Database: MongoDB
- AI API: OpenAI API / Plant Disease Detection API

# Target Users

Farmers and agriculture professionals.
